# Time Scope Phase 1 第三步「打磨」— 人工验证清单

**日期**：2026-10-02　**对应 spec**：`../specs/2026-10-02-phase1-polish-design.md` §9
**代码状态**：自动化已全绿（Rust 253 / 前端 69），下面每一条都**只能人工验证**——
托盘、自启、锁屏的真实行为不经过 Rust 单测覆盖的代码路径。

## 准备

```bash
pnpm install
pnpm tauri dev
```

首次运行会生成 `%APPDATA%\time-scope\config.toml`（带注释的默认模板）。

## 常驻

- [ ] 托盘图标出现在系统托盘，用的是应用图标（不是默认空白）
- [ ] 点窗口的 ✕：**首次**弹出确认框，文案说清「关闭后仍在后台记录」
- [ ] 选「最小化到托盘」→ 窗口消失，任务栏不留残影，**数据继续增长**（切几个窗口后看 db 大小）
- [ ] 选过之后再次点 ✕：**不再弹框**，直接隐藏
- [ ] 托盘菜单三项齐全：打开时间线 / 开机自启（带勾选态）/ 退出
- [ ] 菜单「打开时间线」能把隐藏的窗口叫醒并置前；双击托盘图标等价
- [ ] 托盘菜单能重复打开/关闭窗口多次，不崩
- [ ] 菜单「退出」：进程真的结束，且退出前最后几秒的数据已落盘（看 db 里最后一条 Event 的时间）
- [ ] 再次启动应用：老窗口被叫醒置前，**新进程不残留**（任务管理器里只有一个 time-scope）

## 开机自启

- [ ] 默认状态下托盘「开机自启」是**未勾选**，Windows「启动应用」里没有 Time Scope
- [ ] 勾上 → 注销/重启 → 应用自动启动并出现托盘图标
- [ ] 取消勾选 → 重启 → 应用不再自动启动
- [ ] 在 Windows「启动应用」里**手动删掉**条目 → 重启本应用 → 托盘勾选态显示为未勾选（不是"我们以为的"状态）
- [ ] 改 `config.toml` 的 `autostart = true` → 重启 → 系统里出现条目

## 关窗行为

- [ ] `close_behavior = "quit"` → 重启 → 点 ✕ 直接退出（不弹框）
- [ ] `close_behavior = "minimize"` → 重启 → 点 ✕ 直接隐藏
- [ ] `close_behavior = "ask"` → 重启 → 点 ✕ 又开始问（覆写被改回后重新进入询问态）

## 锁屏与睡眠（本次改动风险最高的部分）

- [ ] 锁屏后等 1 分钟再解锁：时间线出现一段 **idle**，**没有 active 段**，且 idle 覆盖锁屏那段
- [ ] 锁屏前的工作段在锁屏时刻**收尾**，不延伸到锁屏之后
- [ ] 锁屏期间有输入心跳（键盘/鼠标活动）也不产生 work 段
- [ ] 合盖午休 30 分钟后开盖：出现一段 idle（结束时间会**晚于**实际开盖，这是已知限制，spec §3.3）
- [ ] 锁屏 8 小时后查看：那一段是 idle，不是 8 小时 work
- [ ] 锁屏期间不强杀进程：解锁后应用恢复正常采集

## 配置

- [ ] 改 `config.toml` 的 `idle_threshold_s = 10` → 重启 → 停手 15 秒就出现 idle
- [ ] `idle_threshold_s = 0` → 重启 → 仍能启动（被夹到 10），不崩、不产生海量段
- [ ] 把 `config.toml` 写成乱字符 → 重启仍正常（用默认值），**且文件内容没被覆盖**
- [ ] 只写错一个字段（如 `idle_threshold_s = "soon"`）→ 其余字段照常生效
- [ ] 删掉 `config.toml` → 重启 → 自动重新生成默认模板
- [ ] 把 `heartbeat_every_s` 改小（如 2）→ 重启 → 段的数量明显变多（确认参数真的接上了）

## 降级路径（构造困难，只记录）

- [ ] 托盘不可用时（不构造）关窗能退出——已由 `a_failing_tray_must_not_leave_the_app_unclosable` 覆盖逻辑
- [ ] `WTSRegisterSessionNotification` / `PowerRegisterSuspendResumeNotification` 失败时 stderr 有提示且应用照常启动——已由 `a_failed_registration_degrades_instead_of_panicking` 覆盖逻辑
